01

为什么做

影像会散，
档案不会

一场运动会、一次社团招新、一个下午的光，拍下来的时候都在，过两年就散在群聊、云盘链接和各自的手机里了。

这个站做的事很简单：把学校的活动影像、社团作品和可复用的素材收在一起，按类归档，给每一份留下出处与时间。它不追即时新闻，也不做热搜——新闻会过期，档案不会。

对参与的人来说，这是把「我们做过什么」写下来的地方；对还没参与的人来说，这是了解这所学校在发生什么的入口；对很多年以后的人来说，这是一份还能打开的东西。

注 站点由学生维护，内容以归档为主。照片和视频的版权属于拍摄者与所在组织。

02

谁在用

三种身份，
三种权限

  • 游客

    可以看全部公开内容，不需要登录；也可以用只读 WebDAV 挂到自己的设备上浏览。

  • 成员

    用校园墙账号登录后上传照片和视频，文件放在自己的文件夹里——能改名、移动、删除的只有自己上传的那些。

  • 管理员

    管成员、管存储（本地、WebDAV、移动云盘）、管分享链接；上传不限文件类型。

注 账号不开放注册，只能由管理员按 QQ 号手动添加；没被加进来的账号登录会被拒绝。

03

开源

代码是
开源的

前端
纯静态多页站，原生 HTML、一份 CSS、一份 JS，没有框架、没有构建期依赖；图片在构建时重新压过一遍，页面按内容指纹做长缓存。
服务端
Node 原生 http 模块 + node:sqlite，零第三方依赖，同一个进程提供媒体库（/memories）、图床（/image）与只读 WebDAV。
部署
GitHub Actions 构建静态产物并打镜像推送到 GHCR，再滚动更新到香港节点的 k3s 集群；域名与证书走 Cloudflare。
登录
复用校园墙的 OAuth（PKCE），按 QQ 号判定身份，不另存密码。
打开仓库 ↗ 提一个 issue MIT

代码按 MIT 许可开源，可以自由使用、修改与再分发。学校校徽、社团标识、站内照片与视频不在 MIT 授权范围内，版权归学校与各社团所有，转载前请先联系。

注 仓库里还有构建脚本（scripts/build.mjs）、本地预览（scripts/serve.mjs）与 k8s 清单（deploy/），照着 README 可以在自己的机器上跑起来。
